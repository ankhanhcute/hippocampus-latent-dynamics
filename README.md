# Hippocampus Latent Dynamics Decoding

This project explores decoding 2D position from hippocampal spike data using Poisson observation models and latent dynamics.

## Current first milestone

- Load spike and position data
- Check data shapes and alignment
- Plot 2D trajectory
- Build a simple baseline decoder
- Use this baseline before moving into ODE-driven latent dynamics

## Notes

Raw data are not stored in this repository.
